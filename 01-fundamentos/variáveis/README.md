# 🛒 Compra de Produto

Programa em Java que calcula o valor total de uma compra com base na quantidade informada pelo usuário e no preço unitário de um produto.

## 🎯 Objetivo
Praticar a declaração de variáveis com tipos primitivos e de referência, manipulação de entrada de dados pelo terminal e exibição de saída formatada.

## 🛠️ Conceitos Praticados
- Declaração e inicialização de variáveis (`String`, `float`, `int`).
- Entrada de dados pelo console utilizando `Scanner.nextInt()`.
- Operações aritméticas de multiplicação (`*`).
- Formatação de saída com `System.out.printf` (`%d`, `%s`, `%.2f` e quebra de linha `%n`).
- Fechamento de recursos com `scanner.close()`.

## 💻 Exemplo de Execução
```text
Digite a quantidade desejada de teclado
3
O valor de 3 teclado ficou em R$ 1050,00 reais
```
